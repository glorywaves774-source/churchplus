Install ChurchPlus

iPhone or iPad (Safari): tap {{ icon('share', 16) }} Share, then Add to Home Screen.

Android (Chrome): tap the {{ icon('more-vertical', 16) }} menu, then Install app or Add to Home screen.

Computer (Chrome or Edge): click the install icon at the right of the address bar.

The app opens full screen like any other app. For privacy, church records are not stored on the device.
